Installation des fichiers Solar Only ou Solar + Turrets
Les deux dossiers modifient le fichier blocksConfig du jeu, mais avec des effets différents :

Solar Only :
- Augmente la limite de panneaux solaires à 500
- Réduit leur consommation CPU
- Autorise leur placement sur les vaisseaux mères

Solar + Turrets :
-Inclut toutes les modifications de Solar Only
-Augmente également le nombre maximum de tourelles sur tous les éléments qui peuvent en accueillir

Procédure d’installation
1 Ouvrir le dossier d’installation du jeu
- Vous devez accéder aux fichiers internes pour remplacer la configuration.
- Ouvrez l’explorateur de fichiers
- Naviguez jusqu’au dossier où le jeu est installé (Steam, Epic ou installation manuelle)
- - Exemple Steam : C:\Program Files (x86)\Steam\steamapps\common\NomDuJeu

02 Accéder au dossier de configuration
- Le fichier à remplacer se trouve dans le dossier config.
- Ouvrez le dossier config situé dans le répertoire du jeu
- Vérifiez que le fichier blocksConfig.ecf (ou blocConfig) est présent

03 Choisir la version du mod
Important
- Sélectionnez le fichier correspondant aux fonctionnalités que vous souhaitez.
- Pour augmenter uniquement les panneaux solaires → utilisez Solar Only
- Pour augmenter panneaux solaires et tourelles → utilisez Solar + Turrets

04 Remplacer le fichier blocksConfig
- C’est l’étape qui applique réellement les modifications.
- Copiez le fichier blocksConfig du dossier choisi
- Collez-le dans le dossier config du jeu
- Acceptez le remplacement du fichier existant

05 Lancer le jeu et vérifier
- Lancez le jeu
- Affichez toutes les constructions (touche H).
- Si les panneaux solaires et le chargeur affichent un point rouge et jaune, la modification est bien appliquée.
